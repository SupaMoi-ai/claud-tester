Resolve L5 stations

The build environment for Track 5 cannot reach api.entur.io, so js/transport/stations.js ships with approximate coordinates and no NSR StopPlace IDs. Without those IDs the app cannot request a real departure board and falls back to its synthetic timetable.

This page runs in your browser, where Entur is reachable. It looks up all 19 stations through Entur's geocoder, shows you what came back so you can check it, and prints a replacement for the STATIONS array. Nothing is written automatically — you paste the result in yourself.

It is also the quickest way to find out whether Entur allows browser requests from wherever you are serving this. If every row fails with a network error, that is a CORS or connectivity problem, not a data problem — and the app's fallback exists precisely so that stays survivable.
